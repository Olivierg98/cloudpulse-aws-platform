# Engineering learning notes

Use this document after deployment so interview answers reflect work actually completed.

## Problem encountered

What failed or behaved differently from the plan?

## Evidence gathered

Which logs, metrics, Terraform output or AWS events narrowed the cause?

## Root cause

What technical condition created the failure?

## Resolution

What changed, and how was the fix validated?

## Trade-off

What did the chosen solution cost in money, complexity, security or availability?

## What I would change at larger scale

Explain the next architectural step without claiming the portfolio already implements it.
